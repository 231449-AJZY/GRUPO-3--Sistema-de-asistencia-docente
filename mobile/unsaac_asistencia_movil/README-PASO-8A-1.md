# Paso 8A.1 Mobile

Actualización de la aplicación móvil UNSAAC Asistencia.

## Incluye

- Acceso móvil para Administrador y Docente.
- Panel móvil diferenciado por rol.
- Pantalla inicial pública.
- Opción de asistencia rápida sin inicio de sesión.
- Ingreso de código institucional.
- Solicitud real de biometría mediante Android.
- Mensaje explícito cuando la biometría fue aprobada.

## Importante

Esta etapa no registra todavía una asistencia en PostgreSQL. La verificación real del vínculo entre el código y el celular se implementará en el Paso 8B; la firma y el registro definitivo en el Paso 8C.
